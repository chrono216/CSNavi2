# CSnavi2 開発者向けメモ

このプロジェクトに参画する開発者・協力者向けのドキュメントです。

## `img` フォルダの構成と命名規則

画像リソースは `www/img` フォルダ内に格納されています。各フォルダの用途とファイル名の命名規則は以下の通りです。

| フォルダ名 | 用途 | 命名規則・形式 | 備考 |
|---|---|---|---|
| `banner` | TOP画面の特集バナー画像 | `banner01.png` など | `banner01-03.json` と連動して表示されます。 |
| `genreico` | ジャンル一覧画面の各ジャンル横のアイコン | `{ジャンルID}.png`<br>(例: `02.png`, `24.png`) | `app.js` の `App.Data.genres` の `id` と一致します。 |
| `ico` | アイドル（グループ）アイコン<br>および 楽曲ジャケット | - `{任意の英数字}.png` (例: `G9999.png`, `U9999.png`)<br>- `{6桁の数字}.png` (例: `830023.png`)<br>- `{S+5桁数字}.png` (例: `S99999.png`) | 【アイドルアイコン】<br>`gurakara.json` や `umamusume.json` の `icoID` と連動。<br>【ジャケット表示ルール】<br>`6桁の数字.png` は楽曲専用ジャケットファイルです。これが存在しない場合は `S99999.png` のような親曲IDに基づいたジャケットファイルを使用します。どちらもない場合は非表示となります。 |
| `machinetype` | 楽曲詳細・リスト等に表示されるカラオケ機種のロゴ | `{機種コード3桁}.png`<br>(例: `101.png`, `010.png`) | CSVデータ内の `model_code` に基づきます。 |
| `musictype` | 曲タイプごとのカテゴリ一覧表示用アイコン | `{タイプコード3桁}.png` | `list_select.html` 等で曲タイプを絞り込む際に使用されます。 |
| `songtype` | 楽曲ごとの曲タイプアイコン（リスト内表示用） | `{タイプコード3桁}.png`<br>(例: `002.png`) | CSVデータ内の `type_code` に基づきます。 |
| `genretype` | **現在未使用** | - | プロジェクト全体で参照箇所がありません。 |

## `csv` フォルダの構成

楽曲データや各種設定、リストのデータは `www/csv` フォルダ内にJSONおよびCSV形式で格納されています。

| ファイル名 | 用途 | 構造・備考 |
|---|---|---|
| `db.csv` | **楽曲のマスターデータ** | 全ての楽曲情報（曲名、歌手名、番号、機種、タイプ等）が収録された最も重要なファイルです。 |
| `csselect.json` | TOP画面のCSセレクト一覧用データ | 表示したい楽曲の選曲番号（`request_number`）の配列が格納されています。 |
| `banner01.json` ~ `03` | バナー1〜3の楽曲リスト用データ | バナーをタップした際に表示される楽曲の選曲番号が格納されています。 |
| `newsong01.json` ~ `03` | 最新配信曲リスト用データ | 月別の新曲等の選曲番号が格納されています。 |
| `gurakara.json` | グラカラジャンル用データ | アイドル名（`groupName`）、アイコンID（`icoID`）、楽曲配列のリストです。 |
| `umamusume.json` | ウマ娘ゲーム映像ジャンル用データ | 同上。ウマ娘関連の曲リストです。 |
| `models.json` | カラオケ機種のマスターデータ | 機種コード（`001`等）と機種名・説明の紐付けデータです。 |
| `musictype.json` | 曲タイプのマスターデータ | 曲タイプコードと名称・説明の紐付けデータです。 |
| `animetitle.json` | アニメタイトル一覧用データ | アニメタイトルの配列が格納されています。 |
| `releasenote.json` | アプリのリリースノート用データ | バージョンごとの更新履歴（日付、内容）が格納されています。 |
| `songtype.json` | **現在未使用** | プロジェクト全体で参照箇所がありません。 |
| `genre.json` | **現在未使用**（予備） | プロジェクト全体で参照箇所がありません。 |
| `favorites.json` | **現在未使用** | プロジェクト全体で参照箇所がありません。お気に入り初期データ等の名残です。 |
